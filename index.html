这个应用是做什么的 / What this application does

Bayesian（贝叶斯的钟摆） 是一个由个人开发者编写并仅供本人使用的本地程序。 它解决的是一个很具体的问题：开发者本人制作科普、思想、科技投资类的对话视频， 每期成片需要上传到自己的 YouTube 频道。手工上传需要在网页上反复填写标题、简介、标签、 上传封面、等待转码，一期节目要花十几分钟。本应用把这套重复操作自动化： 在开发者本人的电脑上读取已经做好的视频文件与写好的文案，调用 YouTube Data API 上传， 并在上传完成后读取返回结果，确认视频确实发布成功、封面确实生效。

English. Bayesian（贝叶斯的钟摆） is a locally-run desktop tool written by and used only by its developer. It automates one specific chore: uploading the developer's own video programs (science, philosophy and tech-investment conversations) to the developer's own YouTube channel. It reads finished video files and prepared metadata sitting on the developer's machine, calls the YouTube Data API to upload them, and verifies the resulting video and thumbnail afterwards.

应用的使用方式 / How it is used

  1. 开发者在自己的电脑上准备视频文件与标题、简介、标签等文案；
  2. 开发者本人使用自己的 Google 账号完成一次 OAuth 授权（授权令牌保存在本机）；
  3. 程序调用 YouTube Data API 上传视频，默认上传为私有（private）状态；
  4. 上传后程序读取视频信息与封面状态，确认无误；开发者本人再决定是否公开。

程序不是面向公众的网站或服务，没有注册入口，也没有除开发者本人以外的任何用户； 它不会代表任何第三方上传内容。

申请并使用的 Google 权限 / Google API scopes used

https://www.googleapis.com/auth/youtube.upload —— 上传视频到开发者本人的频道。
https://www.googleapis.com/auth/youtube.readonly —— 读取上传结果与视频信息，用于确认上传成功。

除此之外不申请任何其他 Google 权限，不读取 Gmail、Drive、通讯录、日历或任何其他 Google 服务的数据。

数据处理摘要 / Data handling summary

  • 处理的唯一数据是开发者本人的 OAuth 刷新令牌，以及开发者自己填写的视频元数据；
  • 全部数据仅保存在开发者本人的电脑上，不上传到任何第三方服务器；
  • 不使用、不存储、不共享任何其他用户的个人数据——本应用没有其他用户；
  • 不出售数据，不用于广告，不用于训练任何模型；
  • 对 Google API 返回数据的处理遵循 Google API Services User Data Policy， 包含其中的 Limited Use 要求。详见 隐私政策。

关于 AI 生成内容的声明 / AI-generated content

本应用不生成任何影像或音频内容——它只上传开发者本人已经录制、剪辑完毕的视频文件。 本应用不生成、不存储、不上传、不传播任何 AI 生成的非自愿亲密影像（AI NCII）， 与此类内容没有任何关联。

This application does not generate any imagery or audio. It only uploads video files already recorded and edited by the developer. It does not generate, store, upload, or distribute AI-generated non-consensual intimate imagery (AI NCII) in any form, and has no connection to such content.

合规说明 / Compliance

本应用遵守 Google APIs Terms of Service 与 Google API Services User Data Policy， 包括 Limited Use 条款：从 Google API 获得的数据仅用于提供本页面所述的单一功能（上传开发者本人的视频）， 不转移给第三方，不用于广告，不被开发者以外的人读取，也不用于训练通用 AI/ML 模型。
