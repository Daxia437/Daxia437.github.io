Privacy Policy / 隐私政策

App: AI Production Studio — YouTube Publishing (OAuth client for personal automated video publishing)
Last updated: 2026-10-29

English

This application ("AI Production Studio") is a personal, self-hosted automation tool used only by its developer to upload the developer's own videos to the developer's own YouTube channel via the official YouTube Data API.

What data is handled: Google OAuth tokens (used solely to authenticate API calls to the developer's own channel) and video metadata (title, description, tags) provided by the developer.

Where data is stored: Locally on the developer's own computer only. No data is transmitted to or stored on any third-party server other than Google's own API endpoints.

What we do NOT do: We do not collect, share, sell, or analyze any user data. We do not access any other user's Google account or YouTube data. There are no other users.

Contact: the developer, via the developer contact email registered in the Google Cloud Console for this project.

中文

本应用（AI Production Studio）是一个仅供开发者本人使用的本地自动化工具，通过 YouTube 官方 Data API，把开发者自己制作的视频上传到开发者自己的 YouTube 频道。

处理哪些数据：Google OAuth 令牌（仅用于对本开发者自己频道的 API 身份验证）以及开发者自行提供的视频元数据（标题、简介、标签）。

数据存放在哪里：仅保存在开发者本人的本地计算机上。除 Google 官方 API 端点外，不向任何第三方服务器传输或存储数据。

我们不做什么：不收集、不共享、不出售、不分析任何用户数据；不访问任何其他用户的 Google 账号或 YouTube 数据；本应用不存在其他用户。

联系方式：开发者本人，可通过本project在 Google Cloud Console 中登记的开发者联系邮箱联系。

Scope note: 本应用仅申请 youtube.upload 与 youtube.readonly 权限，用于视频上传与上传状态校验。/ This app only requests the youtube.upload and youtube.readonly scopes for uploading videos and verifying upload status.
