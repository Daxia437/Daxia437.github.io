Privacy Policy / 隐私政策

App: Bayesian（贝叶斯的钟摆）— YouTube Publishing · Last updated: 2026-10-29 · 中文与 English 同等效力

1. 概述 / Overview

Bayesian（贝叶斯的钟摆）是一款仅供开发者本人使用的本地桌面自动化工具（下称「本应用」）。它的唯一功能是：把开发者本人制作、本人拥有全部权利的视频文件，通过 YouTube 官方 Data API v3 上传到开发者本人的 YouTube 频道的草稿箱或私享列表，并在上传完成后通过 API 校验上传状态、视频 ID 与封面是否生效。本应用不分发、不出售、不面向任何第三方用户。

Bayesian (the "Application") is a personal, self-hosted desktop automation tool used exclusively by its developer. Its sole function is to upload video files created and fully owned by the developer to the developer's own YouTube channel as drafts or private videos via the official YouTube Data API v3, and to verify upload status, video ID, and thumbnail via the API. It is not distributed to or used by any third party.

2. 我们处理的数据 / Data we process

  • Google OAuth 令牌（access token 与 refresh token）：由 Google 在开发者完成 OAuth 授权后签发，仅用于对开发者本人频道的 API 调用做身份验证。令牌保存在开发者本机磁盘的本地文件（secrets/youtube/token.json）中，不上传到任何第三方服务器。
  • 视频元数据：标题、描述、标签、隐私状态、封面图与字幕文件——全部由开发者在本地配置文件中自行填写。
  • 本应用不收集：任何浏览记录、位置信息、通讯录、广告标识符，也不使用 Cookie、分析统计或埋点。

English: The Application processes only (a) Google OAuth tokens issued to the developer, stored solely in a local file on the developer's computer and used exclusively to authenticate API calls to the developer's own channel; and (b) video metadata (title, description, tags, privacy status, thumbnail, subtitles) authored by the developer in local configuration files. The Application collects no browsing history, location, contacts, advertising identifiers, cookies, or analytics.

3. 数据如何使用 / How data is used

  • 用 OAuth 令牌调用 YouTube Data API：上传视频、设置元数据、上传封面、查询上传结果。
  • 用 API 返回的视频 ID 与状态做本地记录，便于开发者核验。
  • 除此之外无任何其他用途。/ No other use whatsoever.

4. 数据存放与保留 / Storage & retention

  • 所有数据（令牌、元数据、生成的发布记录）仅存储在开发者本人的计算机硬盘上。
  • 令牌有效期由 Google 控制；开发者可随时删除本地令牌文件，或随时在 myaccount.google.com/permissions 一键撤销本应用的全部访问授权——撤销后本应用立即失去任何 API 能力。
  • English: All data resides on the developer's own computer. The developer may delete the local token file at any time, or revoke the Application's access instantly at myaccount.google.com/permissions.

5. 第三方 / Third parties

本应用唯一的网络通信对象是 Google 官方端点（oauth2.googleapis.com、www.googleapis.com、www.youtube.com）。除此之外没有任何第三方：无分析服务、无广告网络、无云存储、无遥测。

English: The only network endpoints are Google's own official APIs. No analytics, advertising networks, cloud storage, or telemetry of any kind are involved.

6. AI NCII 声明 / AI NCII statement

本应用不生成、不存储、不上传、不传播任何 AI 生成的非自愿亲密影像（AI-Generated Non-Consensual Intimate Imagery, AI NCII）。本应用与生成式影像内容无任何关联：它只把开发者本人录制并制作的节目视频上传到本人频道。本应用亦不用于、不支持且不会被用于任何违反 Google API 服务条款的内容。

English: The Application does not generate, store, upload, or distribute AI-generated non-consensual intimate imagery (AI NCII) in any form. It has no connection to generative imagery: it only uploads the developer's own recorded programs to the developer's own channel, in full compliance with the Google APIs Terms of Service.

7. 儿童与适用范围 / Children & applicability

本应用不面向儿童，也不面向任何外部用户——其唯一使用者与唯一数据主体是开发者本人。/ The Application is not directed at children and has no external users; its only user and only data subject is the developer.
