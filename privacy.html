1. 一句话说明 / Summary

Bayesian（贝叶斯的钟摆） 是一个由个人开发者编写、仅供开发者本人使用的本地工具。 它不使用、不收集、不存储任何第三方的个人数据——因为它没有第三方用户。 它唯一处理的数据是开发者本人的 Google 授权令牌，以及开发者自己撰写的视频信息， 这些数据全部保存在开发者本人的电脑上。

This application is a single-user local tool. It has no users other than its developer, and therefore collects no personal data from anyone else. The only data it handles is the developer's own Google authorization token and video metadata written by the developer, all of which stays on the developer's own computer.

3. 处理哪些数据 / What data is processed

数据项来源用途
Google OAuth 刷新令牌（refresh token）与访问令牌（access token） 开发者本人在 OAuth 授权页点击同意后由 Google 颁发 代表开发者本人调用 YouTube Data API 上传视频。令牌保存在本机文件中，权限范围仅为 youtube.upload 与 youtube.readonly
视频文件、标题、简介、标签、封面图片 开发者本人撰写与制作 作为上传内容提交给 YouTube
上传结果（视频 ID、处理状态、封面状态） YouTube Data API 返回 用于确认上传是否成功，记录在本地日志中

不处理：Gmail、Google Drive、通讯录、日历、位置、浏览记录、设备标识、Cookie 追踪数据， 以及任何其他用户的任何数据。

4. 数据如何使用 / How the data is used

仅用于一个目的：把开发者本人制作的视频上传到开发者本人的 YouTube 频道，并确认上传结果。 不用于广告投放，不用于用户画像，不用于统计分析，不用于任何形式的内容推荐。

5. 数据存放与保留 / Storage and retention

  • 存放位置：开发者本人的电脑（本地文件系统），不上传至任何第三方服务器；
  • 传输范围：仅与 *.googleapis.com（YouTube Data API）通信；
  • 保留期限：令牌保留至开发者主动撤销授权或删除本地文件为止； 上传日志保留 90 天后自动清理；
  • 删除方式：删除本地令牌文件即完成删除，也可在 Google 账号的第三方应用授权页 撤销本应用的访问权限，撤销后令牌立即失效。

6. 是否共享给第三方 / Sharing with third parties

不共享。本应用不出售、不出租、不交换、不转让任何数据给任何第三方， 不使用第三方分析 SDK、广告 SDK 或崩溃上报服务。 唯一的数据接收方是 Google（YouTube Data API），用于完成上传这一项功能本身。

7. 与 Google API 服务用户数据政策的一致性 / Google API Services User Data Policy

本应用对从 Google API 获得的信息的使用与转移，遵守 Google API Services User Data Policy， 包括其中的 Limited Use（有限使用）要求，具体而言：

  • 仅将数据用于提供或改进本政策第 4 节所述的单一功能；
  • 不将数据转移给第三方（法律强制要求的情形除外，且会事先告知开发者本人）；
  • 不将数据用于广告用途，包括再营销、兴趣定向投放；
  • 不允许人工读取数据，除非：开发者本人对特定数据给出明确同意、出于安全目的（如调查滥用）、 或为遵守法律而必须读取；
  • 不使用数据训练或改进任何通用的 AI/ML 模型。

8. 安全性 / Security

令牌文件保存在开发者本人的电脑上，不随代码仓库分发，不写入公开日志。 上传过程使用 HTTPS 与 Google API 通信。由于本应用为单用户本地工具，不存在多用户数据混用的风险。

9. 儿童 / Children

本应用不面向公众提供服务，也不面向 13 岁以下儿童，不收集任何儿童的数据。

10. AI 生成内容 / AI-generated content

本应用不生成任何影像、音频或文本内容，只上传开发者本人已经录制和剪辑完毕的视频文件。 本应用不生成、不存储、不上传、不传播任何 AI 生成的非自愿亲密影像（AI NCII）， 也不提供任何可用于生成此类内容的功能。

11. 政策变更 / Changes to this policy

如本政策发生实质变更，将更新本页顶部的"最后更新"日期，并在页面显著位置说明变更内容。 继续使用本应用即表示接受更新后的政策。
