Privacy Policy / 隐私政策

App: Bayesian（贝叶斯的钟摆）— YouTube Publishing · Last updated: 2026-10-29

应用用途 / What this app does

中文：这是一个仅供开发者本人使用的本地自动化工具。它的唯一用途是：把开发者自己制作、拥有完整权利的视频（科普类、思想类与科技投资类对话节目），通过 YouTube 官方 Data API 上传到开发者本人的 YouTube 频道，并在上传后校验上传状态与封面。不用于任何其他目的。

English: A personal, self-hosted automation tool used only by its developer. Its sole purpose is to upload the developer's own videos (science, philosophy, and tech-investment dialogue programs that the developer produces) to the developer's own YouTube channel via the official YouTube Data API, then verify the upload status and thumbnail. It is not used for any other purpose.

Google API 使用声明 / Google API compliance

本应用仅申请并使用 youtube.upload 与 youtube.readonly 两个权限，只操作开发者本人的频道与内容。

本应用不生成、不存储、不上传、不传播任何 AI 生成的非自愿亲密影像（AI NCII）。本应用与 AI NCII 无任何关联：它只把开发者本人录制的节目视频上传到本人频道。/ This application does not generate, store, upload, or distribute AI-generated non-consensual intimate imagery (AI NCII) in any form. It only uploads the developer's own recorded programs to the developer's own channel.

完整隐私政策见：https://daxia437.github.io/privacy.html
